# HolyCrab CLI v0.7.2

- 新增 Kling 4.0、Kling 4.0 Flash、MiniMax H3 Image 和 Highspeed，模型目录共 22 个。CLI、MCP 和 Skills 共用能力声明。
- 支持 Seedance 2.5 的 480p 样片和 1080p 转正片。正片提交绑定已确认报价，复用已关联正片，未知提交结果不自动重发。
- 素材按目标模型判断可用性，非 Seedance 不受 Ark 审核状态统一阻断；工作流区分素材处理中和明确失败并显示具体原因。
- 更新创作指南、五语安装指南、安装器和下载包。Skills 内容版本 1.0.2，最低 CLI 0.7.2；保留已有配置、安装选择、工作流和提交记录。

验证范围及待办见 `v0.7.2-implementation.md` 和 `v0.7.2-live-generation.md`。Generate 后端未修改；Audio 1.5 和视频超分留待后续版本。
