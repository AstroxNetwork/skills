# v0.6.0 对抗性审查记录

基线：`ea4b8ac4c6a5bdc6656ab39c9759ad0991fdeb5d`。范围为 CLI、MCP、安装器及测试；后端只读。正式发布仍等待用户确认。

## 已修复问题与回归依据

| 问题 | 修复与证据 |
| --- | --- |
| PowerShell 5.1 产生的 BOM 请求文件不能读取 | 检测 UTF-8/UTF-16 BOM，严格解码；非法编码明确失败，不替换非法字节 |
| 损坏或不同用户的 DPAPI 密文阻止重新配置和清除 | 更换/清除不先解密旧密文；保留其他配置项，原生用例验证同用户及跨用户 |
| 非法 Key 可进入请求头，多行管道只读取首行 | 统一验证 Key 字符，整份管道输入验证；错误不包含凭据，不存储、不联网 |
| EOF 产生异常堆栈 | 安全退出 130，明确没有因该输入获得授权 |
| HTTP 206 或 Content-Range 响应被保存为完整文件 | 拒绝部分响应，保留原文件；实际 HTTP 验证 206、截断和重定向 |
| Windows 无覆盖下载依赖硬链接 | Windows 使用同目录、不覆盖目标的 rename，覆盖路径仍用原子 replace |
| 提交期间 purge 能删除防重记录 | 使用配置目录外的稳定操作锁；活动生成/上传持有共享锁，purge 非阻塞获取独占锁；屏障控制实际提交并验证拒绝清理 |
| 确认后估算变化仍可能按原确认提交 | 交互模式提交前复核；CLI/MCP 增加可选已确认金额，金额变化不记录尝试、不提交；不声称锁定后端最终费用 |
| 畸形 URL 造成脱敏异常 | 解析失败按敏感 URL 脱敏，不输出令牌 |
| MCP 空数组/false/null 被默认为有效空对象 | 保留字段类型，明确返回协议或工具错误 |
| Windows 安装解释器选择与路径风险 | 优先当前 Python，候选不可运行则继续；拒绝不安全安装位置；CMD 启动器关闭延迟展开，保护解释器路径 |
| 测试框架可能接受 expectedFailure、部分证据及残留进程 | expectedFailure 失败；完整必需 ID、双源码指纹、架构/版本检查；进程组/Windows Job Object 清理 |

## 测试有效性

`tools/run_checks.py --profile adversarial` 运行安装后的进程及本机 HTTP 故障服务。16 模型的路径、参数预期独立编写；22 MCP 工具分别断言业务结果，远程工具还断言错误结果和请求次数。上传与生成并发使用固定屏障；没有随机等待来猜测竞争时机。

`tools/run_mutation_checks.py` 在临时副本依次执行基线与十种已编译的行为缺陷。必须发生断言失败才能认为测试抓住缺陷；测试异常、缺报告、跳过或超时不能当作通过。变异运行时的哈希重算确保测试越过安装健康检查。

Windows 的基线 60 项跳过有逐项映射；跨平台测试恢复执行，纯 Unix 与网站外部验收单列，必要行为须有同一源码的原生用例。`windows_native_cases.json` 是完整必需列表，报告缺项即失败。原生普通用户、真实控制台及文件共享锁的结果只能由对应 Windows 作业证明。

## 验收记录与边界

具体通过数量、失败日志、系统版本、解释器、Shell、权限与源码指纹见该提交的 CI `validation-*` 工件。检查定义或历史提交的结果不能替代候选实际结果。最终说明应引用同一个已验证提交。

Windows 10/11 x64 桌面尚未实测，Windows 11 ARM 不能替代它；第三方网络盘和所有文件系统组合也未穷举。真实上传、真人授权、付费生成及线上部署不包含在离线验收。估算后至服务端最终扣费之间缺少后端原子报价绑定，此次仅增加提交前金额复核。
