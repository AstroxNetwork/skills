## 确认并修复的问题

1. 工作流预览在 A 目录批准 `A/movie.mp4`，切换到 B 目录后执行却写入 `B/movie.mp4`。执行阶段现使用批准记录中已展开的绝对 destination，覆盖相对路径及 `~`/HOME 变化；已有批准记录含该字段，无须迁移。
2. 下载服务器返回 HTTP 200 空内容时，CLI 原先报告成功，`--force` 可将原视频替换为空文件。现于原子交付前拒绝零字节结果，保留旧文件、移除临时文件。覆盖 Content-Length:0、空 chunked、无长度头三种情况及新建/覆盖场景。

修改运行代码仅限 `workflows.py` 与 `downloads.py`；新增回归测试在 `test_creative_workflows.py` 和 `test_download_integrity.py`。安装清单与两平台安装器哈希已刷新，候选包重新生成。
