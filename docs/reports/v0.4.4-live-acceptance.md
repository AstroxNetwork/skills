## 发现与修复

- 旧更新器把“不接入 Agent”转换为空字符串，安装器误用默认值：现在从安装记录恢复原设置，明确的 `none` 同样保留。
- 非交互更新失败只显示笼统错误：增加有长度限制、脱敏的安装器错误输出。
- 安装失败回滚可能影响未选 Agent、额外文件或另一个已完成的客户端：按实际改动恢复托管文件和对应连接，不完整恢复保留备份。
- 未安装的可选 Claude 客户端被在线自检误报为故障：仅对明确未登记的客户端标记 `not-installed`；原有受管连接失效仍报错。真正的连接修复指向安装器，不再推荐不会重装的版本检查。
- 测试驱动最初错误地按 JSON 解析 clear-key 的文字结果，现已按公开输出处理。
- 本机 Homebrew ffprobe 缺少依赖，备用二进制架构不适用：使用 macOS 原生解码器检查，未改动用户的软件依赖。
