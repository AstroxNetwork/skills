# Local finished-video export
Use media compose or a compose workflow step to turn downloaded clips into one MP4. All media inputs are selected local files; remote URLs and playlists are not accepted by this local editor. Query media doctor before planning a render. HOLYCRAB_FFMPEG and HOLYCRAB_FFPROBE can name explicit executables. Missing or broken binaries need user-controlled installation; never install tools silently.

Request: clips is a non-empty array of {path,start?,duration?,text?}; output is the destination .mp4. width/height default 1920/1080, fps defaults 30, fit is contain (default) or cover. mute=true removes all audio. narration and music are optional local paths; musicVolume defaults 0.15 and sourceVolume defaults 1. narration replaces original clip audio. Subtitle input is either subtitles (a local .srt/.ass path), captions [{start,end,text}], or clip text timed to that clip. These choices are mutually exclusive. Exact speech alignment is not supplied; segment times come from the approved storyboard or subtitle file.

Run media compose --json @edit.json without --yes to preview the timeline, file hashes, dimensions and output path. Then run with --yes --approval-hash HASH after user approval. MCP media_compose has the same confirmed/approvalHash contract. Editing does not spend HolyCrab credits. Existing output is never overwritten unless force=true was explicitly approved. A file change invalidates the preview.

Inputs are trimmed explicitly, normalized to one canvas/fps and concatenated. Missing source audio becomes silence. Narration must fit the full timeline; music loops at the requested level. Export H.264/AAC MP4 (or video-only when muted). Subtitle text is treated as text, not ASS override commands. The editor selects an available CJK font on common macOS/Linux/Windows installations. To choose another font, supply a local font path (.ttf/.otf/.ttc) and its fontFamily. The preview hashes the font file too. Missing subtitle glyphs fail rendering; inspect CJK and Latin examples during validation.

Successful completion includes output path, duration, dimensions and verification. Retain source clips and the edit specification. If generation/download/compose fails, report the completed pieces and the blocked step, not a finished video. Ask for an explicit revision instead of automatically regenerating clips.
