# MiniMax H3 prompt adaptation
Identify the supported input mode using the installed H3/H3 Max/H3 Highspeed/H3 Lite capability. Read h3/base-en.txt for text or keyframe composition, or h3/ref-en.txt for full-reference rewriting. Preserve structured prompt sections and stable reference labels. Dialogue and visible scene text stay in the requested language.

The upstream prose teaches creative structure, not the API request schema. Fields such as integrated_multimodal_description, overall_soundscape and non_diegetic_music belong inside prompt content, not invented top-level request arguments. Use actual HolyCrab model IDs, duration/resolution and supported combinations from capability_get. Do not send Seedance generateAudio to H3. Do not infer H3 Max limits from a base-H3 writing example.

Read execution.md before API calls and workflows.md for multi-shot execution. For prompt-only requests do not upload or generate. Describe each shot's composition, action, camera and sound, and align the prompt timeline with the chosen supported duration.

Highspeed and Lite require CLI 0.7.1. Highspeed supports 768P; Lite supports 480P/768P; both use 4–15 integer seconds. Lite text/reference requests require a concrete ratio, while frame mode uses adaptive. Query the exact model capability; never substitute base-H3 limits or quote a fixed price.
